# ExpatReader（增量阅读器）

A personal attempt to improve reading experience for second language learners.

个人电脑浏览器使用的轻量电子书阅读器。Vue 3 + TypeScript + Vite，foliate-js 负责阅读，Dexie 保存本地数据，MiniSearch 提供读者与 AI 共用的检索。

仅解释读者主动查询的词句；学习模式显示已有解释。AI 按需检索、读取原文，以引用支持回答，不移动阅读页面。

开发顺序、验收节点见 [开发大纲](开发大纲.md)。过程记录见 [开发记录](开发记录.md)。原始讨论稿保持原样。

已接入本机 Codex 订阅登录，支持动态模型列表、推理强度、阅读 Chat 与按书保存的对话。实现边界和后续适配方式见 [本地 Agent 接入设计](docs/local-agent-design.md)。

项目仓库：[ExpatReader](https://github.com/skyrider996/ExpatReader)。个人电子书放入 `books-local/`，个人备份放入 `backups-local/`，密钥不提交。

## 启动

需要 Node.js 22.12+ 或 24+；当前验证环境为 Windows、Node 24、Edge。

日常使用双击项目目录里的 **`启动阅读器.cmd`**。它会检查并启动后台本地服务，再用默认浏览器打开固定地址 <http://127.0.0.1:4173/>；服务正常时直接复用。启动窗口关闭后，服务继续运行。首次使用仍需先安装下方依赖；缺少构建产物时启动入口会自动构建。

如果重启电脑、休眠恢复或结束运行会话后地址打不开，再次双击即可。休眠本身不一定结束服务；该入口不设置开机自启。请使用原来的浏览器及用户资料，保持 `127.0.0.1:4173` 地址，以访问原有书籍和记录。端口被其他程序占用时会提示错误，不结束其他程序；启动日志保存在 `.cache/reader.out.log` 和 `.cache/reader.err.log`。

以下为开发时的手动启动方式：

```powershell
cd D:\Epub_workspace
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>。正式构建及本地预览：

```powershell
npm run build
npm run preview
```

预览地址为 <http://127.0.0.1:4173>。两个端口属于不同浏览器存储空间；日常使用固定一个地址。端口占用时程序报错，不自动换端口。应用需要本地服务，不能直接双击 `index.html`。

## 使用

### 基础阅读

- 书库显示封面、书名、作者，支持搜索与按最近阅读/书名排序。旧书打开一次后会补充封面与作者；没有可用封面时显示文字封面。
- 打开书籍后默认收起侧栏。左上角返回书库，目录按钮打开章节列表；目录可筛选，并标记当前章节。返回书库再打开同一本书会继续原位置。
- 底部提供字号、分页/滚动、翻页和全书进度跳转。进度按书籍内容估算；“第几节”是 EPUB 内容文件序号，包含前言等内容，不是纸书页码。
- 顶部「阅读排版」可选字体、行距、每页宽度、单双页和明亮/纸张/夜间主题。设置自动保存在当前浏览器；双页会随窗口宽度适配，学习模式仍使用滚动。
- 顶部「专注阅读」收起工具栏，按 Esc 或右下角按钮退出。←/→、Page Up/Page Down 可翻页；输入框内不会触发翻页。「更多工具」里可切换浏览器全屏。
- 刷新阅读页会续读；在书库刷新则保留书库界面。请保持相同浏览器与访问地址。

### 已有附加功能

目录、搜索、排版、笔记、学习和设置集中在左侧；词典与翻译、独立 AI 对话位于右侧。

1. 导入无 DRM、可重排 EPUB。原文件以 Blob 存入本地浏览器；刷新后自动打开上次阅读的书。
2. 选中原文会自动出现浮选框，提供标注、复制、书内搜索，以及按选区显示的查词或翻译。标注可用浅褐色、品红色、浅绿、浅蓝；重选同一处高亮或其中一部分可换色或取消。取消高亮会保留已有笔记或学习记录。右侧以富文本显示查询结果，可手动补充或主动点击「AI 解释」。
3. 开启「学习模式」后，已有解释显示在所属段落下方，阅读布局切换为滚动。没有查询过的文字不会被自动翻译。同词在不同位置分别保存。
4. 「搜索」使用本地原文索引。「上下文」仅预览；「回到原文」才跳转。如果索引尚未完成，主动搜索会优先完成索引再返回结果。
5. 「笔记」支持修改、删除、按章节查看与 Markdown 导出。「学习」可将解释转存为独立笔记，之后删除学习记录不影响笔记。
6. 「更多工具 → 设置」可导出/恢复个人记录。JSON 包含所有书籍的批注、学习记录和进度，不包含书籍本体与模型密钥。新浏览器恢复后，重新导入完全相同的 EPUB 文件即可关联；不同版本的文件不会自动混合。

## 模型设置

在「设置 → AI 模型」选择连接方式：

- **本机 Codex（订阅登录）**：复用本机 Codex 管理的 ChatGPT 登录。自动检测可执行文件，也可填写 `codex.exe` 的绝对路径；连接后从账号返回的列表选择模型与推理强度（effort）。未登录时，点击「登录 Codex」并打开官方登录页面，完成后刷新连接。当前已实测并启用的 CLI 版本为 `0.167.0-alpha.3.2`；其他版本需先更新兼容适配，不会自动放宽工具权限。
- **直接连接 API**：填写兼容 Chat Completions 的 HTTPS 基础地址（如 `https://你的服务/v1`）或完整 `/chat/completions` 地址、模型 ID 和密钥。
- **本地 Agent 服务**：自行启动 Agent，在阅读器中填写带端口的 `http://127.0.0.1:端口/v1` 或完整 `/chat/completions` 地址、服务要求的模型 ID 和可选访问令牌。阅读器不安装、不启动 Agent，也不会代替用户登录。Agent 必须提供兼容 OpenAI Chat Completions 的非流式 JSON 请求与响应，并支持 `tools`、`tool_calls` 和 `tool` 消息，才能使用带引用的书籍问答；不兼容的服务需要先自行适配。

直接 API 与兼容接口本地服务均由浏览器直接请求，接口需允许阅读器页面的跨域请求（包括 JSON 和可选 Authorization 请求头）。兼容接口本地服务还可能受浏览器本地网络访问权限限制，其订阅资格取决于对应 Agent。Codex 使用阅读器同源本机连接，不需要另行配置跨域或 API 密钥；阅读器不复制登录令牌，也不会在登录失效或额度不足时自动切到付费 API。

API 设置只保留在当前页面会话，刷新后清空。Codex 的连接方式、可执行文件路径、模型与 effort 保存在本浏览器；修改选择作用于下一轮。只有主动点击查询/提问，原文和问题才会发送给模型服务。阅读、本地搜索和已有记录不依赖模型网络。

Codex 固定使用「Chat · 阅读对话」：可解释、讨论和按需查证原文，关闭命令、文件编辑、电脑操作和额外 MCP/插件等执行入口。Ultra 依赖多 Agent 执行，在阅读 Chat 中不可选。每本书分别保存对话，可新建、切换和删除本地对话记录；刷新后恢复最近会话。对话及其引用不包含在现有个人记录备份中；删除本地记录不删除 Codex 自己的历史。选中文字后，在右侧词典面板点击「AI 解释」可生成并保存语境解释，相同位置优先读取已保存记录；可取消进行中的解释。

本地连接程序仍可能调用云端模型，问题和按需读取的原文会发送至模型服务，继续受订阅额度限制。运行数据及上游会话映射位于忽略目录 `.cache/reader-agent/`；不要在有在途请求时手动清理。Codex 自身继续管理其登录和原生会话历史。

AI 通过共享内容服务调用 `getOutline`、`searchBook`、`readPassage`、`readSection`。不能移动页面、修改笔记或执行书中指令。每轮最多 8 次工具调用、30,000 字符原文；API 使用 90 秒单次请求超时，Codex 使用分阶段超时及五分钟整轮上限。引用卡片只对应实际读取的原文；这保证引用能溯源，不代表模型的分析一定正确。模型未提供有效引用时界面明确提示。

已用本机 Codex 的真实订阅完成原创测试文本的解释、原文工具、引用、effort 切换、续聊和取消验证；其他 API 提供商仍主要通过模拟接口验证。具体结果及既有测试限制见开发记录。

## 实现边界

- 上游 foliate-js 固定 1.0.1，锁文件跟踪完整依赖。CFI 过滤通过实例适配实现，没有改写 `node_modules`。
- 阅读页先完成显示，再在空闲时间分片准备全文检索。段落前后文通过一次遍历计算，DOM 相关工作按短时间片让出页面；分词、索引建立、查询和索引缓存读写放在 Worker。完整索引按书籍内容哈希和格式版本持久化，再次打开可直接恢复；缓存损坏或版本不符时重建。主动搜索会跳过初始等待并优先完成索引，避免把尚未收录的原文误报成没有结果。
- 无云同步、账号、全文翻译、PWA 离线安装或全书自动总结；电脑本地服务运行时可断网阅读已存书籍。
- 仅测试桌面 Edge 的上述样本与场景，不能视为所有 EPUB、Chrome 版本或特殊排版均已兼容。
- 浏览器清理站点数据会移除本地书籍和记录；请定期导出个人记录并自行保存原始 EPUB。
- 选区快捷菜单按正文 iframe 中的可见选区定位；翻页、滚动、重排或调整窗口时关闭，重新选中后可再次打开。学习记录通过正文标记和侧栏查看，不把解释插入原文。

详细测试证据和阶段提交见 [开发记录](开发记录.md)。

## 词典和翻译

打开书籍后，在「更多工具 → 设置 → 词典与翻译」分别选择词典服务和翻译服务。选中单个词，浮框显示「查词」；选中短语、句子或段落，显示「翻译」。点击相应按钮后才发送所选文字；右侧面板使用同样的分流规则，结果可编辑后保存为学习记录。

默认 Free Dictionary API 返回英文释义；Wiktionary 使用英语版的多语言词条，释义语言及词源信息取决于词条内容。两者适合查询单词，不保证每个词都包含词源。Wiktionary 的结构化释义接口属于实验性接口，可能变化或不可用，内容使用须遵守其许可。

Google Cloud Translation 和 DeepL 是翻译服务，需用户自行开通、填写密钥与目标语言代码，可能产生费用。DeepL 分 Free 和 Pro 端点。密钥仅保存在当前页面会话，刷新后清除，不包含在备份中；词典、翻译服务选择及翻译目标语言保存在当前浏览器。翻译请求经绑定到本机的阅读器服务转发。请使用本项目的启动入口或 `npm run dev` / `npm run preview`，纯静态文件托管不支持该转发。若阅读器服务在更新前已经运行，需退出旧服务并重新启动后使用翻译功能。


## 个性化、在线书源与缓存

- 「阅读排版 → 自定义」支持背景和字体颜色：可以用取色器选色，也可以输入 R、G、B（0–255）。颜色立即应用到正文和阅读器主题，并保存在当前浏览器；切换预设后仍保留自定义配色。
- 书库的「在线书源」及阅读页「更多工具 → 在线书源」支持公开 HTTPS EPUB 直接下载链接，以及 [OPDS 1](https://specs.opds.io/opds-1.1.html) / [OPDS 2](https://specs.opds.io/opds-2.0.html) 目录。可保存自己的书源、浏览目录层级和下一页、筛选当前目录，再将可直接取得的 EPUB 加入本地书库。需要账号、购买、借阅或 DRM 的流程暂不支持，也不支持任意网页正文抓取。
- 在线文件通过本机服务下载；每本不超过 50 MB，目录不超过 3 MB。重定向会重新校验公开 HTTPS 地址；不代理本机、内网或带账号密码的地址。书源列表保存在本浏览器，个人记录 JSON 备份暂不包含书源列表。
- 「设置 → 缓存与笔记」显示实际缓存目录、文件数量和占用空间。输入新的完整父目录后，服务创建专用的 `ExpatReader-cache` 子文件夹，迁移现有缓存后再切换配置。默认目录为项目内 `.cache/reader-books/`，配置保存在 `.cache/book-cache-settings.json`；该路径是服务共用的，使用同一本机服务的浏览器共享文件缓存。
- 缓存是经过内容指纹校验的 EPUB 副本，用于再次打开书籍；书库原件、笔记和阅读位置仍保存在浏览器数据库。「清除缓存」清理阅读器管理的书籍副本及浏览器中保存的检索索引，不删除书库原件、笔记、学习记录、阅读位置或 AI 历史，也不清理 Codex 登录数据。下次打开书籍会从本地书库重新生成书籍副本和检索索引；这不会改变浏览器自身数据库的存储目录。
- 设置中的「导出笔记」导出所有书籍的批注为 Markdown，保留书名、章节、选中的原文与定位；原有「笔记 → 导出 Markdown」仍只导出当前书籍。导出学习记录和进度请使用「导出个人记录」。
- 更新后若旧的本机服务仍在运行，请重新启动阅读器服务，使新增书源和缓存接口生效。
