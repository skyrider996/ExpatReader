# 基础阅读界面

2026-10-20：按用户要求暂停扩展附加功能，优先完善基础阅读。

## 参考与取舍

实地查看了 [Flow](https://app.flowoss.com/zh-CN) 的书库、官方样书和阅读页，并参考其[官方项目说明](https://github.com/pacexy/flow)。采用其书库与阅读分开、正文优先、章节与进度轻量显示的思路。界面自行实现；不复制其代码、品牌或资源，也不引入其框架。

本轮不加入多书分屏、云同步、远程书籍链接、账户或新的 AI 能力。

## 交互

1. **书库**：封面卡片、作者、最近阅读、书名排序和搜索。读取 EPUB 自带的栅格封面；没有封面或封面无法解析时显示文字封面。
2. **阅读**：侧栏默认关闭。顶部保留返回、目录、搜索、排版、专注及更多工具。章节标题可打开目录。目录支持筛选，并跟随当前章节高亮。
3. **排版**：字号、字体、行距、单页宽度、单双页、分页/滚动、明亮/纸张/夜间主题。全局偏好只保存在本地；保留书籍标题与图片布局。
4. **导航**：底部翻页与进度滑块；正文及页面空白处支持方向键和 Page Up/Page Down。输入控件和文本选区不会被翻页快捷键干扰。
5. **续读**：返回书库先保存位置；打开当前书复用阅读器；刷新读取上次位置。用户在书库刷新时继续显示书库。
6. **专注/全屏**：专注模式收起主要工具栏，Esc 或明确按钮可退出；浏览器全屏单独提供。

## 实现约束

- Vue 只管理界面，排版和导航由 ReaderAdapter 封装；排版重排与导航串行执行，在操作真正开始时读取原文位置，避免排队期间恢复到旧位置。
- 原文 CFI、引文校验、检索和批注结构沿用现有实现。封面与作者是 books 表的可选非索引字段，不重建数据库。
- 封面限制为不超过 5 MB 的常见栅格格式；不在书库渲染书内 HTML/SVG。封面对象 URL 在更新和组件卸载时释放。
- 排版设置独立于模型设置。恢复排版不修改个人记录；密钥仍只在页面会话中保存。
- 页底百分比来自 foliate-js 的内容进度估算，不伪造纸书页码；节数采用 EPUB 内容文件序号。
